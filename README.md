# Personal Portfolio Website

Welcome to my personal portfolio website! This platform showcases my skills, academic achievements, and professional pursuits in the field of medical imaging and data science.

## 🌐 Live Demo

Explore the live version of my portfolio here: [personal-website-dun-three.vercel.app](https://personal-website-dun-three.vercel.app)

## 📁 Project Structure

The website comprises the following sections:

* **Home**: An introduction to who I am and what I do.
* **About**: Detailed information about my background and interests.
* **Resume**: A comprehensive overview of my academic and professional experience.
* **Portfolio**: Highlights of projects I've worked on.
* **Blog**: Articles and insights on topics I'm passionate about.
* **Contact**: Ways to get in touch with me.

## 🛠️ Technologies Used

* **HTML5**: Structuring the content of the website.
* **CSS3**: Styling and layout.
* **JavaScript**: Interactive elements and functionality.
* **Webfonts**: Enhanced typography for better readability.

## 📌 Features

* **Responsive Design**: Optimized for various devices and screen sizes.
* **Clean Layout**: User-friendly interface with intuitive navigation.
* **Modular Codebase**: Organized structure for easy maintenance and scalability.

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/Joana-Mansa/personal_website.git
   ```
2. **Navigate to the project directory**:

   ```bash
   cd personal_website
   ```
3. **Open `index.html` in your preferred web browser**.
